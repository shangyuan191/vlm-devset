# 屬性標註準則 v1

你是家具家飾商品的屬性標註員。你會看到一張或多張商品主圖（每張圖前面有它的 item_id），請依照這份準則，替每一張圖標出 5 個維度（style、category、color、material、shape）和每個維度的信心（1–3）。每張圖獨立判斷，不要和其他圖比較。

總原則：

- 只依**圖片中看得到的特徵**判斷，不要猜品牌、不要依常識推測看不到的部分。
- 普通人看圖就能分辨，才算有那個風格；沒有明確特徵就選 `mixed/none`。
- 每個維度只能選**一個**值，而且必須是下面列出的選項之一（照抄英文）。
- 圖中有多件東西時，標**主要商品**（最大、最居中、最完整的那一件）。成套的相同商品（例如 2 張一樣的椅子、2 盞一樣的燈）當成一件來標。場景照（商品擺在房間裡）只標商品本身，不標背景的家具。

## 1. style（風格）

選項（11 個）：`mid-century modern` | `industrial` | `farmhouse/rustic` | `bohemian` | `coastal` | `traditional` | `modern minimalist` | `scandinavian` | `glam` | `other` | `mixed/none`

| 值 | 顏色 | 材質 | 線條 / 造型 | 裝飾程度 |
|---|---|---|---|---|
| `mid-century modern`（中世紀現代） | 胡桃木、柚木的中深棕；點綴芥末黃、橄欖綠、橘、青綠 | 中深色實木、布面、黃銅細節、白色球形玻璃 | **向外斜張的錐形細腳**、低矮、圓角或有機曲線、一體成型的殼狀椅座；燈具有球形燈泡、放射狀（Sputnik）、圓錐或圓頂金屬燈罩 | 低：幾乎沒有雕花 |
| `industrial`（工業風） | 黑、鐵灰、深棕、鏽色 | 黑鐵 / 鋼管、鑄鐵、粗糙原木、裸露的愛迪生燈泡 | 水管與接頭、鉚釘、X 形或 U 形金屬腳、金屬籠形燈罩、滑輪、齒輪 | 低到中：裝飾來自「結構外露」 |
| `farmhouse/rustic`（農舍鄉村風） | 白、米、灰綠、做舊木色 | 刷白或做舊的木頭、粗木、鍍鋅金屬、麻、格紋布、雞籠網、梅森罐 | X 形支架、穀倉門、車輪形吊燈、粗木紋、厚重樸實 | 中：手作感、做舊痕跡 |
| `bohemian`（波西米亞） | 多色、暖色、大地色（赭、磚紅、芥末） | 藤、麻、流蘇、編織（macramé）、刺繡布、串珠 | 不對稱、層疊圖案、圖騰、曼陀羅、流蘇垂墜 | 高：圖案多、手工感 |
| `coastal`（海岸風） | 白、沙色、淺藍、海軍藍 | 漂流木、繩、貝殼、海玻璃、白色或淺色藤編 | 明亮輕盈；航海或海洋元素（船舵、錨、繩結、貝殼、珊瑚、魚、海浪、燈塔） | 中：主題元素 |
| `traditional`（傳統古典風） | 深色木、酒紅、墨綠、古銅、金色點綴 | 深色實木、錦緞、皮革釘扣、古銅或黃銅 | 雕花、捲邊扶手、彎腿或獅爪腳、車旋柱腳、對稱、翼背、燭台式吊燈、甕形燈座 | 高：雕刻與釘扣 |
| `modern minimalist`（現代極簡） | 黑、白、灰單色，或單一金屬色 | 光滑烤漆、金屬、玻璃、平滑布面 | 純直線或純幾何、沒有多餘結構、沒有復古細節 | 很低 |
| `scandinavian`（北歐風） | 白、淺灰、粉嫩色 + 淺木（樺、橡、梣） | 淺色實木、羊毛 / 毛氈、柔和布面 | 簡潔、圓角、細木腳、功能性、溫暖感 | 很低 |
| `glam`（華麗風） | 金、銀、鏡面、黑白對比、寶石色 | 絲絨、水晶、鏡面、亮面金屬、大理石 | 高光澤、簇絨、水晶垂飾 | 高：閃亮 |
| `other` | — | — | 有**明確**風格，但不是上面 9 個（例如 Art Deco、Tiffany 彩繪玻璃、亞洲 / 日式、熱帶、摩洛哥、卡通童趣、哥德、西部牛仔） | — |
| `mixed/none` | — | — | 看不出任何明確風格（一般、普通的商品），或同時有兩種以上風格的特徵且分量相當 | — |

### 相近風格怎麼分（依序套用，套得上就照它選）

1. **mid-century modern vs scandinavian vs modern minimalist**
   - 有斜張錐形腳 / 有機曲線，而且木色是**中到深**（胡桃、柚木）或有飽和的復古色（芥末黃、橘、青綠）或黃銅 → `mid-century modern`。
   - 同樣的簡潔造型，但木色是**淺色**（樺、橡、原木白）配白 / 淺灰 / 粉嫩色、有柔軟溫暖的布料 → `scandinavian`。
   - 沒有木頭的溫暖感、沒有復古細節：單色、金屬 / 玻璃 / 烤漆、純幾何 → `modern minimalist`。
   - 例外：一體成型塑膠殼椅座 + 木釘腳的經典椅（Eames 型）一律 `mid-century modern`。
   - 球形玻璃 + 黃銅桿的燈、Sputnik 放射狀吊燈 → `mid-century modern`；只有一個單色幾何燈體、沒有復古元素 → `modern minimalist`。
2. **coastal vs bohemian**
   - 有海洋 / 航海元素，或整體是白 + 藍 / 沙色的明亮配色 → `coastal`。
   - 有流蘇、macramé、圖騰、曼陀羅、多色或暖色大地色 → `bohemian`。
   - **只有藤編 / 草編、沒有以上任何一種線索**（例如素面藤編吊椅、藤編燈罩）→ `bohemian`，信心最多給 2。如果藤編被漆成白色或搭配藍白布料 → `coastal`。
3. **industrial vs farmhouse/rustic**（木頭 + 金屬的商品很常見）
   - 金屬是主角（黑鐵框架、水管、鉚釘、籠形燈罩、裸露燈泡）→ `industrial`。簡單的「黑鐵架 + 木板」桌或層架也算 `industrial`，信心最多給 2。
   - 木頭是主角，而且有刷白、做舊、粗木、X 形支架、穀倉門、鍍鋅鐵皮、車輪形 → `farmhouse/rustic`。
   - 兩者分量相當、分不出來 → `mixed/none`。
4. **traditional vs glam vs farmhouse/rustic**
   - 木頭雕花、彎腿、古銅色渦卷的「繁複」→ `traditional`；水晶、鏡面、亮面金屬、絲絨的「閃亮」→ `glam`；樸素、做舊、手作感 → `farmhouse/rustic`。
   - 水晶吊燈 → `glam`；古銅 / 黑鐵的燭台式渦卷吊燈（沒有水晶）→ `traditional`。
5. 仍然分不出來 → `mixed/none`，信心給 1。

### 掛畫、海報、掛毯等牆面裝飾（wall art）的風格

看**畫面內容、配色和外框**：

- `coastal`：海灘、海浪、貝殼、船、燈塔、海洋生物，藍白沙色。
- `bohemian`：曼陀羅、macramé 壁掛、流蘇、圖騰、太陽月亮、大地色的抽象拱形 / 色塊、蒲葦、扎染。
- `mid-century modern`：復古配色（芥末黃、橘、青綠、棕）的抽象幾何、星芒（starburst）、迴力鏢形、復古海報風。
- `farmhouse/rustic`：做舊木板、農場動物（牛、雞、豬）、穀倉、棉花、黑白格紋、鄉村風標語字板、舊木窗框。
- `industrial`：齒輪、金屬板、機械 / 專利藍圖、鉚釘、都市磚牆、鐵件。
- `traditional`：古典油畫風的風景 / 靜物 / 人像、復古植物或鳥類圖鑑版畫、雕花金框。
- `modern minimalist`：黑白線條畫、極簡單色幾何、大量留白。
- `glam`：金箔、亮片、時尚精品圖像、大理石紋配金。
- 一般照片、名人海報、電影 / 動漫 / 遊戲海報、地圖、勵志標語、宗教圖像、兒童卡通等，如果不符合上面任何一種 → `other`（主題明確但不在清單內）或 `mixed/none`（沒有可辨識的家飾風格）。

## 2. category（品項）

選項：`chair` | `sofa` | `table` | `stool/ottoman` | `cabinet/storage` | `shelf` | `bed` | `lamp` | `chandelier/pendant` | `other lighting` | `wall art` | `rug` | `other`

- `chair`：單人座椅（餐椅、扶手椅、躺椅、辦公椅、搖椅、戶外椅、吊椅）。沒有椅背的是 `stool/ottoman`；兩人以上座位是 `sofa`。
- `table`：茶几、邊桌、玄關桌、餐桌、套桌。書桌也算 `table`。
- `lamp`：放在桌上或地上的燈（桌燈、落地燈、檯燈）。
- `chandelier/pendant`：從天花板**垂吊**下來的燈（吊燈、單頭吊燈、中島吊燈）。
- `other lighting`：吸頂燈（貼著天花板，沒有垂吊）、壁燈、軌道燈、燈串、夜燈、燈泡、燈罩等其他燈具。
- `wall art`：掛在牆上的畫、海報、照片、掛毯、壁掛雕塑、壁飾。
- 桌椅成套的商品：標面積最大的主要品項。不屬於以上任何一類 → `other`。

## 3. color（主要顏色）

選項：`white` | `black` | `gray` | `beige/cream` | `brown` | `natural wood` | `blue` | `green` | `red/pink` | `yellow/orange` | `metallic` | `multicolor`

- 選商品本身面積最大的顏色（不看背景）。沒有任何單一顏色占一半以上 → `multicolor`。
- 看得到木紋的木頭 → `natural wood`（不論深淺）；漆成不透明棕色或棕色皮革、布料 → `brown`。
- 金、銀、黃銅、鉻、古銅等有金屬光澤的表面 → `metallic`；漆成黑色或白色的金屬 → `black` 或 `white`。
- **燈具（`lamp`）看燈座 / 燈身，不看燈罩**。只有在沒有可見的燈座、燈身時（例如整個就是一個發光燈罩）才看燈罩。
- **吊燈（`chandelier/pendant`）看燈體的主要結構**（燈架、燈臂、燈罩外殼），不看燈泡、吊鍊、電線和天花板底座。單頭吊燈的主體就是燈罩，所以看燈罩；玻璃透明燈罩 + 金屬燈架的看金屬燈架。
- 掛畫看整個畫面（多數會是 `multicolor`）。

## 4. material（主要材質）

選項：`wood` | `metal` | `fabric` | `leather` | `rattan/wicker/rope` | `plastic/acrylic` | `glass` | `stone/ceramic/concrete` | `paper/canvas`

- 選面積最大、看得到的材質。軟墊椅：椅面椅背包覆的材質（`fabric` 或 `leather`，人造皮也算 `leather`）；只有薄坐墊的木椅 / 金屬椅看框架。
- 桌子：桌面和桌腳材質不同時，看**桌面**。
- 燈具規則和顏色相同：`lamp` 看燈座 / 燈身，不看燈罩；`chandelier/pendant` 看燈體的主要結構，單頭吊燈看燈罩。水晶吊燈 → `glass`。
- 掛畫、海報、照片、畫布 → `paper/canvas`；掛毯、macramé → `fabric`（繩編的 macramé 選 `rattan/wicker/rope`）；金屬或木頭壁飾照實際材質。
- 樹脂、看不出來的合成材質 → `plastic/acrylic`，信心給 1。

## 5. shape（外形輪廓）

選項：`rectilinear`（方正直線）| `curved`（圓弧流線）| `round`（圓形 / 球形 / 筒形）| `angular/geometric`（幾何稜角、斜面、多面體、放射狀）| `organic/irregular`（不規則、自然形）

- 看整體剪影，不看細節裝飾。
- 椅子：方正的椅背椅座 → `rectilinear`；圓弧椅背、桶形、殼形 → `curved`；圓形（如圓盤椅、蛋形吊椅）→ `round`。
- 桌子：看**桌面形狀**為主：長方形 / 正方形 → `rectilinear`；圓桌、圓筒 → `round`；橢圓 → `curved`；六角形等 → `angular/geometric`；原木切片等自然形 → `organic/irregular`。
- `lamp`：看**燈座 / 燈身**（不看燈罩）：直桿、方柱 → `rectilinear`；球形、圓筒、圓罐 → `round`；葫蘆形、花瓶形、弧形落地燈的彎臂 → `curved`；三腳架、幾何多面體 → `angular/geometric`；漂流木、樹枝、動物造型 → `organic/irregular`。
- `chandelier/pendant` 等**多部件商品，看整組燈的外圍輪廓**，不看單一燈頭：圓環形、車輪形、鼓形、球形、單一圓頂 / 圓罩 → `round`；長條形（中島燈）、方框形、方燈籠 → `rectilinear`；放射狀（Sputnik）、多面體籠、幾何線框 → `angular/geometric`；向上彎曲的燈臂（燭台式）、水滴形、鐘形 → `curved`；樹枝狀、不對稱垂墜、多盞高低錯落 → `organic/irregular`。
- 掛畫：看外框輪廓（長方形 → `rectilinear`、圓形 → `round`）；沒有邊框的不規則壁掛（macramé、金屬雕塑）→ `organic/irregular`。多幅成組的畫看單一幅的形狀。

## 6. confidence（信心，每個維度各給一個 1–3 的整數）

- `3` = 很確定，任何人看圖都會同意。
- `2` = 大致確定，但有一個相近選項也說得通。
- `1` = 不確定、看不清楚，或只是勉強選一個。
